# Build Notes

Recommended production stack:
- Next.js
- Supabase or Firebase
- Vercel
- Stripe
- S3-compatible storage
- OpenAI or other multimodal AI provider
- Tavily / Brave Search / SerpAPI / Bing Search API
- PDF generator
- Email provider
- Analytics with explicit user consent

## Important production tasks

1. Add auth and user accounts.
2. Add real database models for users, projects, conversations, reports, goals, uploads, research logs, sources, and milestones.
3. Add server API routes for AI calls.
4. Add server API routes for web search.
5. Add secure image/file upload.
6. Add moderation and safety filters.
7. Add privacy policy and consent logs.
8. Add data export and deletion backend jobs.
9. Add payment and plan enforcement.
10. Add parent/guardian controls for minors.
11. Add PDF report generation with citations.
12. Add source quality and confidence scoring.
